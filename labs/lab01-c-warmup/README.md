# lab01 — 환경 확인과 C 워밍업

## 오늘의 최소 목표

```
make hello && ./hello
```

**GPU 이름이 화면에 나오면 성공이다. 오늘 반드시 도달해야 하는 지점은 여기까지다.**

뒤의 C 워밍업과 도전 과제는 못 끝내도 된다. 집에서 이어서 해도 되고,
아예 못 해도 다음 랩에 지장이 없다. 먼저 위 한 줄부터 통과시켜라.

## 환경 확인

아래 순서대로 진행한다. 어느 단계에서 막히든, 그 줄에 적힌 것만 확인하고
그래도 안 되면 손을 들어라. 혼자 오래 붙들고 있지 말 것.

| 단계 | 명령 | 실패하면 확인할 것 |
|---|---|---|
| 1 | 실습실 PC 로그인 | 본인 계정으로 로그인했는가. 원격 접속이라면 GPU가 없는 서버일 수 있다 |
| 2 | `nvidia-smi` | 표가 안 나오면 드라이버 문제다. 재부팅 한 번, 그래도 안 되면 손을 든다 |
| 3 | `nvcc --version` | `command not found` 면 PATH 문제다. `/usr/local/cuda/bin` 이 PATH에 있는가 |
| 4 | `make hello` | 컴파일 오류가 나면 3단계로 돌아간다 |
| 5 | `./hello` | GPU 이름과 `threadIdx.x` 네 줄이 나오면 끝이다 |

`./hello` 는 문제가 생겨도 죽지 않는다. 무엇을 확인해야 하는지 한국어로 알려주고
정상 종료한다. 화면에 나온 안내를 먼저 읽어라.

## C 워밍업

여기부터는 `nvcc` 가 필요 없다. `gcc` 만 있으면 된다.
CUDA 툴킷에 문제가 있어도 이 부분은 진행할 수 있다.

```
make
./warmup
```

`warmup.c` 에는 함수가 세 개 있다. 모든 행렬은 **1차원 배열 하나**로 표현하고
`A[row*N + col]` 로 접근한다. 이 감각을 만드는 것이 오늘의 목적이다.

| 함수 | 상태 |
|---|---|
| `mat_add` | 완성되어 있다. 나머지 둘의 본보기다 |
| `mat_mul` | `// TODO:` 를 채운다 |
| `mat_transpose` | `// TODO:` 를 채운다 |

처음 실행하면 `mat_add` 만 `PASS` 가 나온다. 정상이다.
`TODO` 를 채우고 다시 `make` 후 `./warmup` 을 돌린다.

검증은 두 단계로 나온다. 1절은 손으로 계산해 볼 수 있는 작은 크기이고,
2절은 큰 크기에서 반드시 성립해야 하는 성질(`A + 0 = A`, `A x I = A`,
두 번 전치하면 원래대로)로 확인한다.

크기는 인자로 바꿀 수 있다. `./warmup 256` 처럼 쓴다. 기본값은 512다.

`mat_transpose` 는 정사각이 아닌 경우도 검사한다. 정사각만 맞추면
`rows` 와 `cols` 를 바꿔 써도 통과하기 때문이다.
